RUBY'S BIRTHDAY WEBSITE — RUBY ♡ MONI

1. Unzip this folder.
2. Open the folder in Visual Studio Code.
3. Install the VS Code extension "Live Server" (by Ritwick Dey).
4. Right-click index.html -> "Open with Live Server".
   The site opens in your browser. You can also double-click index.html to open it,
   but Live Server is better while editing.

CUSTOMIZE:
- Edit the birthday letter in index.html.
- Edit friendship quotes in index.html.
- Edit memory messages in script.js (the "memories" array).
- Change colours/font in style.css if you wish.

API KEY:
This website is a static site and does not need any API key. Don't put private API keys
inside HTML/JavaScript that will be published publicly.

HOST FOR FREE (GitHub Pages):
1. Sign in or create an account at https://github.com
2. Create a new repository, e.g. ruby-birthday.
3. Upload index.html, style.css, script.js (and README if you want).
   Make sure index.html is at the repository root, not inside another nested folder.
4. Open the repository -> Settings -> Pages.
5. Under "Build and deployment", choose "Deploy from a branch".
6. Select branch "main" and folder "/ (root)", then Save.
7. Wait a little for the deployment. GitHub will show your public website URL
   in the Pages section. Share that link with Ruby!

Alternative easy hosting:
- Netlify Drop: https://app.netlify.com/drop
  Drag and drop the folder containing the website files. It will publish and give you a URL.

NOTE: Date countdown isn't included because this page is designed as a birthday-day surprise;
the date is displayed in the hero. If you want a live countdown before the birthday,
you can add one later.
